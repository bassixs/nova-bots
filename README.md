# NOVA lab — Чат-боты в MAX

Статическая посадочная с HTML, CSS и JavaScript без клиентского фреймворка. Основные тексты и все шесть сценариев присутствуют в исходном HTML. Публичный адрес: `https://nova-bots.ru/`; прежний путь `/services/max-bots/` также открывает страницу.

## Работа с проектом

Нужен Node.js 20+. Зависимостей для сборки нет.

```sh
node scripts/build.mjs
node scripts/serve.mjs
```

Предпросмотр: `http://127.0.0.1:4173/`. После изменений выполнить сборку и обновить страницу. Для размещения на статическом хостинге используется содержимое `dist/`.

`src/components.mjs` содержит переиспользуемые шапку, подвал, кнопки, карусель и секции. `src/scenarios.mjs` — содержание примеров. `src/style.css` — токены айдентики, адаптивность и анимации. `src/app.js` — взаимодействия. Manrope хранится локально; лицензия включена.

## Настройки перед рекламным запуском

Все публичные настройки находятся в `site.config.mjs`:

- `origin` — публичный HTTPS-домен. Из него создаются canonical, og:url и sitemap.xml.
- `indexable` — управление индексированием через robots.txt и HTML. Для опубликованного домена включено.
- `title`, `description`, `ogImage` — SEO и Open Graph. Изображение необязательно.
- `contacts.email`, `contacts.phone`, `legalName`, `legalDetails` — реальные контакты и реквизиты. Пустые значения не отображаются.
- `contacts.maxUrl`, `contacts.telegramUrl`, `contacts.vkUrl` — публичные HTTPS-ссылки для MAX, Telegram и ВКонтакте. Пустая или некорректная ссылка оставляет кнопку неактивной с пояснением.

После изменения настроек повторить сборку. Форма заявки и аналитика не подключены: сайт не собирает контакты, не сохраняет рекламные метки и не отправляет их на сервер. Посетитель сам выбирает внешний канал связи.

## Размещение на Host-0

Сайт размещён в каталоге `/www/nova-bots.ru` аккаунта `u3646325` в ispmanager. В корень загружается **содержимое** `dist/`, а не папка `dist` целиком. Публичный адрес — `https://nova-bots.ru/`. Старый стандартный файл хостинга сохранён на сервере как `index.hosting-backup.html`. Доступы к хостингу и GitHub в репозитории не хранятся.

## Способы связи

Блок предлагает MAX, Telegram и ВКонтакте. Переключение вкладок остаётся на странице; внешний сервис открывается только по нажатию кнопки выбранного канала. Кнопки ведут на адреса из `site.config.mjs`.

## Поведение и проверки

Вступительная заставка использует локальный `public/assets/nova-intro.mp4` (копия предоставленного `промо.mp4`, 4,11 секунды, 3840×2160). Видео запускается без звука и без обрезки, затем плавно открывает страницу. Кнопка «Пропустить заставку» и Escape завершают её сразу. Показ один раз за сессию вкладки; для повторного просмотра открыть `/?intro=1`. При reduced motion видео не загружается. Ошибка воспроизведения или загрузка без прогресса дольше 3,5 секунды открывают сайт автоматически. Локальный сервер поддерживает диапазоны байтов для MP4.

Автопрокрутка каждые 7 секунд, ручное переключение, клавиши ←/→/Home/End, свайп по горизонтали. После ручного переключения автосмена отключается до перезагрузки страницы. Кнопки паузы и запуска нет. Наведение, фокус, скрытая вкладка и уход hero с экрана приостанавливают автопрокрутку. Reduced motion отключает её и фоновое движение. При автоматической смене фокус не перемещается. На мобильном панели идут последовательно.

Использован логотип, предоставленный пользователем: `public/assets/nova-logo.png`. Цвета и свечение страницы согласованы с ним. В карусели четыре бизнес-сценария и два для администрации.
