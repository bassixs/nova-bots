# NOVA lab — Чат-боты в MAX

Статическая посадочная с HTML, CSS и JavaScript без клиентского фреймворка. Основные тексты и все шесть сценариев присутствуют в исходном HTML. Рабочий адрес: `/services/max-bots/`; корень также открывает страницу.

## Работа с проектом

Нужен Node.js 20+. Зависимостей для сборки нет.

```sh
node scripts/build.mjs
node scripts/serve.mjs
```

Предпросмотр: `http://127.0.0.1:4173/services/max-bots/`. После изменений выполнить сборку и обновить страницу. Для размещения на статическом хостинге используется содержимое `dist/`.

`src/components.mjs` содержит переиспользуемые шапку, подвал, кнопки, карусель, секции и форму. `src/scenarios.mjs` — содержание примеров. `src/style.css` — токены айдентики, адаптивность и анимации. `src/app.js` — взаимодействия. Manrope хранится локально; лицензия включена.

## Настройки перед рекламным запуском

Все публичные настройки находятся в `site.config.mjs`:

- `origin` — фактический HTTPS-домен. Из него создаются canonical, og:url и sitemap.xml. Пока домен не задан, вымышленные URL не создаются.
- `indexable` — включить после готовности публичного сайта. Сейчас robots.txt и HTML запрещают индексирование.
- `title`, `description`, `ogImage` — SEO и Open Graph. Изображение необязательно.
- `leadEndpoint` — адрес реального сервера приёма заявок; `privacyPolicyUrl` — опубликованная политика обработки данных. Без обоих параметров отправки нет.
- `contacts.email`, `contacts.phone`, `legalName`, `legalDetails` — реальные контакты и реквизиты. Пустые значения не отображаются.
- `metrikaId` — идентификатор счётчика Яндекс Метрики. Пустое значение полностью отключает аналитику.

После изменения настроек повторить сборку. Получатель, ключи почты/CRM и прочие секреты должны храниться только на сервере, принимающем заявки. В статическом проекте получатель не придуман и сервер доставки не подключён.

## Контракт приёма заявки

Форма отправляет JSON через POST на `leadEndpoint`:

```json
{
  "name": "Имя",
  "organization": "Необязательное поле",
  "method": "email | phone | max",
  "contact": "Контакт",
  "task": "Описание задачи",
  "attribution": {"utm_source": "...", "yclid": "..."},
  "page": "/services/max-bots/",
  "consent": {"policy": "URL политики", "acceptedAt": "ISO timestamp"}
}
```

Успех отображается только после HTTP 2xx и JSON `{ "ok": true }`. Этот ответ сервер должен возвращать после надёжного сохранения заявки или подтверждённой доставки получателю. Простого HTTP 200 недостаточно. Ошибка, невалидный JSON, `{ "ok": false }` или тайм-аут не очищают форму. Тайм-аут — 15 секунд. Кнопка блокируется на время запроса. Сервер обязан повторно валидировать данные, ограничивать частоту запросов и разрешать CORS только для нужного домена, если он отличается.

UTM и yclid сохраняются в sessionStorage для текущей вкладки и прикладываются к заявке. Без доступа к storage используются метки из текущего URL. Контактные данные в storage не записываются. События Метрики: `primary_cta_click`, `scenario_interaction` (только номер сценария/тип действия), `form_start`, `lead_confirmed`. Содержимое формы и контакты в события не передаются; Webvisor, автоматическая карта кликов и отслеживание ссылок отключены.

## Поведение и проверки

Автопрокрутка каждые 7 секунд, ручное переключение, клавиши ←/→/Home/End, свайп по горизонтали. После ручного действия запуск возможен только кнопкой воспроизведения. Наведение, фокус, скрытая вкладка и уход hero с экрана приостанавливают автопрокрутку. Reduced motion отключает её и фоновое движение. При автоматической смене фокус не перемещается. На мобильном панели идут последовательно.

Для локальной проверки контракта формы: `node scripts/qa-server.mjs`. Адрес `http://127.0.0.1:4180/?mode=success` даёт тестовый подтверждённый ответ; `mode=reject` — HTTP 200 с `ok: false`; `mode=error` — HTTP 500. Это отдельная локальная фикстура, отсутствующая в `dist` и на опубликованном сайте; она ничего не доставляет. Использовать только синтетические данные.

Визуальный референс не был приложен отдельным изображением: композиция и текстовый логотип созданы по описанию задания. Для точного совпадения фирменного знака потребуется оригинальный SVG NOVA lab.
